# 2. Hardening & Prevention

The cheapest incident is the one the attacker never gets to start. This stage is the mirror of pre-exploitation: close the gaps an attacker would probe before they probe them.

## Sections
1. [Vulnerability Management](./01-vulnerability-management.md) — find, prioritize, and verify patching with real risk context.
2. [Web Hardening](./02-web-hardening.md) — headers, WAF, input handling, TLS, reducing web attack surface.
3. [Credential Defense](./03-credential-defense.md) — LSASS protection, LAPS, tiering, stopping dumping at the source.
4. [Account & Password Policy](./04-account-password-policy.md) — MFA, lockout, service accounts, defeating sprays and roasting.

> Prevention and detection are not either/or. Harden to raise the cost, detect because determined attackers still get through.
